TASK-3 — обработка XML валют ЦБ России

Go 1.22. Точка входа: cmd/service/main.go.
Запуск из папки task-3:
    go run ./cmd/service -config config.yaml

Конфигурация YAML содержит input-file и output-file.
Относительные пути отсчитываются от рабочей директории запуска.
В testdata/currencies.xml находится учебный пример в Windows-1251,
а не актуальные курсы. Путь к XML преподавателя указывается в input-file.
Результат примера: output/currencies.json. Каталоги создаются автоматически.

Как работает программа:
1. main проверяет аргументы и запускает этапы обработки.
2. config читает и проверяет YAML с двумя указанными полями.
3. currency читает ValCurs/Valute через encoding/xml и декодирует Windows-1251.
   XML-структура хранит Value строкой. После чтения целая и дробная части
   разделяются через strings.Cut и проверяются на десятичные цифры. Затем
   число переводится в float64 и помещается в отдельную структуру для JSON.
   Несколько разделителей, точка, экспонента и посторонние символы запрещены.
4. Валюты сортируются по убыванию исходного Value. Nominal и VunitRate
   не участвуют в сортировке: это требование шага 3 упражнения.
В исторических данных без ISO-кодов сохраняются num_code: 0 и char_code: "".
5. encoding/json сохраняет только num_code, char_code, value.
   Права на новые папки и файлы задаются константами в main
   и передаются в currency.WriteJSON аргументами.

Проверяются обязательный -config, пустые пути, синтаксис YAML и XML,
корень ValCurs, числовые значения, ошибки чтения и записи.
Пакеты возвращают ошибки с пояснениями, main завершает работу через panic.
Чтение и запись файлов выполняются через os.ReadFile/os.WriteFile:
отдельных defer для закрытия файлов в нашем коде нет.

Зависимости:
    gopkg.in/yaml.v3 — YAML
    golang.org/x/text/encoding/charmap — Windows-1251
Остальное выполняется стандартными пакетами Go.
Версии зависимостей зафиксированы в go.mod, контрольные суммы — в go.sum.
Для синхронизации используется go mod tidy.

Проверки:
    go test ./...
    go vet ./...
    go build ./...
